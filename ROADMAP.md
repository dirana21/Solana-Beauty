# Roadmap реализации проекта «Solana Beauty»

## Стек и архитектура
- **Фронтенд:** HTML5, CSS3 (Modern Vanilla / CSS Variables, Glassmorphism, Responsive Mobile-first), Vanilla JS (ES6+ Modules, Zero-dependency для максимальной надежности и быстрой отдачи).
- **Бэкенд & База данных:** Node.js + Express + SQLite (через `better-sqlite3` или `sql.js` / локальный JSON/SQLite storage) + Multer (с конвертацией/проверкой изображений WebP/JPEG для 100% совместимости со всеми версиями Safari/iOS/Android).
- **Безопасность:** Защищенная сессия/JWT с HttpOnly cookies, bcrypt хеширование пароля админа, CSRF защита, rate-limiting против брутфорса, sanitization (защита от XSS/HTML Injection), безопасная загрузка файлов (валидация MIME-типа, сигнатур файлов и генерация уникальных safe-имен).
