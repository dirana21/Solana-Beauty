# Solana Beauty — Руководство по проекту и развертыванию

**Solana Beauty** — современный, адаптивный веб-сайт премиум-салона красоты и эстетической косметологии (брови, ресницы, губы, уход за лицом) с полноценной автономной панелью управления для администратора (для мамы).

Сайт полностью подготовлен для развертывания на рынке США (поддержка американских форматов телефонов, адресов, валюты USD `$`, SEO-оптимизация под Google US, микроразметка Schema.org `BeautySalon`).

## 🚀 Как запустить проект локально (для тестирования)

1. Убедитесь, что установлен **Node.js** (версия 18+ или 20+).
2. Откройте терминал в папке проекта.
3. Установите зависимости (если переносится без `node_modules`):
   ```bash
   npm install
   ```
4. Запустите сервер:
   ```bash
   node server.js
   ```
   *или через npm:*
   ```bash
   npm start
   ```
5. Откройте в браузере:
   - Сайт: **http://localhost:3000**
   - Вход в админку: **http://localhost:3000/admin-login**

## 🌐 Инструкция для веб-мастера / хостинга в США (Deployment)

Сайт полностью автономен, не требует настройки тяжелых внешних СУБД (PostgreSQL/MySQL), так как использует надежную локальную SQLite в режиме WAL с нулевой стоимостью обслуживания.

### Вариант 1: Развертывание на VPS / Cloud (DigitalOcean, AWS Lightsail, Hetzner, Linode)
1. Склонировать репозиторий или скопировать файлы проекта на сервер в папку `/var/www/solana-beauty`.
2. Запустить установку зависимостей:
   ```bash
   npm install --production
   ```
3. Запустить через менеджер процессов PM2 (для непрерывной работы 24/7 и автоперезапуска):
   ```bash
   npm install -g pm2
   pm2 start server.js --name "solana-beauty"
   pm2 startup
   pm2 save
   ```
4. Настроить Nginx в качестве Reverse Proxy (проксирование порта 3000 на домен `yourdomain.com`).
5. Выпустить бесплатный SSL-сертификат HTTPS через Certbot:
   ```bash
   certbot --nginx -d yourdomain.com -d www.yourdomain.com
   ```

### Вариант 2: PaaS хостинги (Render, Railway, Heroku)
1. Подключить репозиторий GitHub `Solana-Beauty`.
2. Команда сборки (Build Command): `npm install`
3. Команда запуска (Start Command): `node server.js`
4. Добавить Persistent Disk на путь `/data` и `/public/uploads` (для сохранения базы и загруженных фото).

## 🛡️ Безопасность проекта

- **Пароли:** Хеширование с солью `bcryptjs`.
- **Сессии:** Защищенные `HttpOnly` JWT-cookies.
- **Защита от брутфорса:** Ограничение частоты запросов `express-rate-limit` (максимум 10 попыток входа за 15 минут).
- **HTTP-заголовки:** Интегрирован `Helmet` (защита от XSS, clickjacking, sniff attacks).
- **Безопасная загрузка файлов:** Проверка MIME-типов, допустимых расширений (`.jpg`, `.png`, `.webp`) и генерация безопасных имен файлов с защитой от Path Traversal.
