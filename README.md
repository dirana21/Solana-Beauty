# Solana Beauty — Руководство по запуску и передаче

Сайт премиального косметического салона/клиники **Solana Beauty** (брови, ресницы, губы, перманентный макияж, уход).

---

## 🚀 Как запустить прямо сейчас на компьютере:

1. Откройте терминал в папке сайта (`SiteForMom`).
2. Запустите команду:
   ```bash
   node server.js
   ```
3. Откройте в браузере:
   - **Главный сайт:** [http://localhost:3000](http://localhost:3000)
   - **Вход в панель управления:** [http://localhost:3000/admin-login](http://localhost:3000/admin-login)

### Данные для входа в панель мамы:
- **Логин:** `admin`
- **Пароль по умолчанию:** `Solana2026!`
*(Пароль можно сменить в самой панели управления во вкладке «Studio Contacts»)*

## 👩‍💼 Возможности панели управления (для мамы):
1. **Интерактивный гид и кнопка помощи (?) слева снизу:**
   - При первом входе маме автоматически открывается понятная пошаговая шпаргалка.
   - В любой момент мама может нажать синюю кнопку **«Как здесь всё работает? (?)»** в левом нижнем углу меню, и модальное окно наглядно объяснит, что делает каждая вкладка, куда нажимать и где на сайте это появится.
2. **Создание и удаление разделов (вкладка «Services & Photos»):**
   - Мама может нажать «Create New Section» (например: *Lip Blush*, *Lash Extensions*, *Brows*) — и новый раздел сразу же появляется в навигации сайта и отдельным красивым блоком.
3. **Загрузка фотографий работ:**
   - В каждом разделе есть удобная зона загрузки. Мама просто выбирает фото со своего телефона или компьютера — фото загружается и отображается в галерее раздела с функцией увеличения при клике (Lightbox).
4. **Управление процедурами и ценами:**
   - Добавление процедур с указанием названия, цены ($), длительности и описания в 1 клик.
5. **Редактирование обложки и замена главного фото (вкладка «Hero & Cover»):**
   - Возможность сменить заглавное фото салона/модели на обложке прямо через кнопку загрузки файла.
   - Редактирование главного заголовка, слогана, плашек и всех цифр («100% стерильность», «4,200+ клиентов»).
6. **Редактирование всех смысловых блоков (вкладка «Page Blocks & Standards»):**
   - Редактирование карточек клинических стандартов (стерильность, разметка, гипоаллергенность), а также заголовков галереи и формы записи.
7. **Просмотр заявок клиентов (вкладка «Client Requests»):**
   - Все клиенты, которые заполнили форму «Reserve Your Session», мгновенно отображаются с их телефонами и пожеланиями. Номера кликабельны для прямого звонка или сообщения.
8. **Контакты и соцсети (вкладка «Studio Contacts»):**
   - Мама может прямо в панели изменить номер телефона, WhatsApp, Telegram, Instagram, адрес студии и часы работы без редактирования кода.

## 📍 Вставка пикселей (Meta Pixel, Google Tag, TikTok, VK)
В коде файла `public/index.html` четко размечены области для маркетолога:

1. **В `<head>` (строки ~60–80):**
   ```html
   <!-- ======================================================================
   [PIXEL INSERTION AREA: HEAD]
   PASTE YOUR META PIXEL (FACEBOOK), TIKTOK PIXEL, GOOGLE TAG (GTAG.JS), 
   OR GOOGLE TAG MANAGER CODE DIRECTLY BETWEEN THE MARKERS BELOW:
   ====================================================================== -->
   <!-- START: PIXEL / ANALYTICS HEAD CODE -->
   <!-- Вставьте сюда код пикселя -->
   <!-- END: PIXEL / ANALYTICS HEAD CODE -->
   ```

2. **В начале `<body>` (строки ~90–100):**
   ```html
   <!-- ======================================================================
   [PIXEL INSERTION AREA: BODY (NOSCRIPT)]
   PASTE YOUR META PIXEL NOSCRIPT / GTM NOSCRIPT DIRECTLY BELOW:
   ====================================================================== -->
   <!-- START: PIXEL NOSCRIPT CODE -->
   <!-- Вставьте сюда noscript часть -->
   <!-- END: PIXEL NOSCRIPT CODE -->
   ```

## 📦 Как перекинуть сайт маме или специалисту для выкладки в интернет (Хостинг/Домен):

Сайт полностью автономен и собран по стандарту Node.js. 

### Инструкция для специалиста (хостинг в США):
1. Скопировать всю папку на любой хостинг (DigitalOcean, AWS Lightsail, Render, Railway, Hetzner, cPanel с Node.js, VPS и т.д.).
2. Выполнить `npm install` (если переносится без папки `node_modules`).
3. Запустить через PM2 или systemd:
   ```bash
   pm2 start server.js --name "solana-beauty"
   ```
4. Подключить домен и выпустить бесплатный SSL-сертификат (Let's Encrypt / Cloudflare).
5. Все данные сохраняются в локальной базе `data/solana.db`, а фотографии — в `public/uploads/`. Никаких внешних платных баз данных подключать не требуется!
